LaundryKu

Sistem kasir digital untuk usaha laundry — mengubah pencatatan pesanan yang sebelumnya manual (kertas/buku catatan) menjadi sistem terkomputerisasi yang cepat, akurat, dan dapat menghasilkan laporan otomatis.

Fitur

- Autentikasi & Manajemen Akun — Login berbasis JWT. Akun staf (Admin/Kasir) dikelola oleh Admin, tidak ada pendaftaran akun secara terbuka.

- Role-Based Access Control — Akses dibedakan antara ADMIN dan KASIR sesuai kebutuhan operasional.

- Manajemen Pelanggan — Pencatatan data pelanggan (nama, no. HP, alamat).

- Manajemen Jenis Layanan — Master data jenis layanan dengan dua model harga:
Per kilogram — misalnya cuci reguler, express, setrika
Per satuan barang — misalnya bed cover, sepatu, sprei, boneka, selimut, karpet, gorden

- Pencatatan Pesanan (Order) — Hitung total harga otomatis, generate nomor invoice, lacak status pesanan (DITERIMA → DIPROSES → SELESAI → DIAMBIL).

- Pembayaran — Pencatatan pelunasan (tunai/transfer), status pembayaran otomatis terhubung ke laporan.

- Laporan & Rekap — Rekap transaksi harian, mingguan, dan bulanan (total order & total omzet).

- Riwayat Waktu Otomatis — Tanggal terima, estimasi selesai, tanggal selesai dikerjakan, dan tanggal diambil tercatat otomatis.
